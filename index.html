Panduan & Rumus Akuntansi

Petunjuk penggunaan, prinsip saldo normal akuntansi, dan daftar rumus yang digunakan.

📱
Cara Menggunakan AkuntansiKu
▼
  1. Kalkulator HP Normal: Buka tab Kalkulator HP untuk operasi matematika standar (+, −, ×, ÷, %, 00, 000).
  2. 14 Kalkulator Khusus Akuntansi: Buka tab Kalkulator untuk memilih alat seperti HPP, Kas Kecil, PPh Final UMKM, Gaji Bersih, BEP, dan lainnya.
  3. Tombol Contoh Soal: Di setiap kalkulator tersedia tombol ✨ Contoh Soal untuk menguji dengan kasus riil sekali klik.
  4. Periksa Jurnal: Gunakan tab Jurnal Umum untuk menguji keseimbangan debit dan kredit transaksi akuntansi.
⚖️
Aturan Saldo Normal (Debit vs Kredit)
▼

Aturan penambahan dan pengurangan saldo akun dalam akuntansi berpasangan (double-entry):

Kelompok Akun Saldo Normal Bertambah (+) Berkurang (-)
Harta / Aset (Kas, Piutang, dll) DEBIT DEBIT Kredit
Kewajiban / Liabilitas (Utang) KREDIT KREDIT Debit
Ekuitas / Modal KREDIT KREDIT Debit
Pendapatan (Revenue) KREDIT KREDIT Debit
Beban (Expenses) DEBIT DEBIT Kredit
📐
Rumus-Rumus Akuntansi Praktis
▼
  • Harga Pokok Penjualan (HPP): HPP = (Persediaan Awal + Pembelian Bersih) - Persediaan Akhir
  • Kas Kecil (Imprest): Pengisian Kembali = Total Bon Pengeluaran | Selisih = (Fisik + Bon) - Plafon
  • PPh Final UMKM: PPh = DPP Kena Pajak × 0,5% (Bebas s.d. Rp 500 Juta untuk OP)
  • Gaji Bersih (THP): THP = Penghasilan Bruto - (BPJS + Pajak + Potongan Lain)
  • TVM (Future Value): FV = PV × (1 + r)^n
  • Persamaan Akuntansi: Ekuitas = Aset - Liabilitas
  • Laba / Rugi: Laba/Rugi Bersih = Pendapatan - Total Beban
  • Break Even Point: BEP Unit = Biaya Tetap / (Harga Jual - Biaya Variabel)
  • Penyusutan Garis Lurus: Penyusutan = (Harga Perolehan - Nilai Residu) / Umur Manfaat
  • Current Ratio: Current Ratio = Aset Lancar / Liabilitas Lancar

Fitur & Jaminan Kualitas Edisi Final Resmi
▼

Aplikasi ini adalah Edisi Final Resmi yang telah disempurnakan dengan standar penuh untuk siswa, mahasiswa, dan profesional:

  • Penyimpanan Permanen: Seluruh baris Jurnal Umum dan Riwayat Kalkulasi kini otomatis tersimpan di localStorage peramban Anda dan tidak akan terhapus saat halaman di-refresh.
  • Ekspor Dokumen: Dilengkapi fitur ekspor ke format Microsoft Excel (CSV) dan opsi Cetak / Simpan PDF langsung dari browser ponsel atau laptop.
  • Dapat Di-install (PWA): Siap ditambahkan ke Home Screen smartphone Anda sebagai web app mandiri.
  • Keamanan 100% Offline: Seluruh perhitungan berjalan di perangkat lokal Anda tanpa pengiriman data keuangan ke server eksternal.
